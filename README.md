# Hostello - Hotel & Resort Booking Website

This project is a frontend final project developed as part of the Full Stack Development course at Mziuri School.

The goal of the project is to build a modern, responsive, and visually cohesive multi-page website for a luxury boutique hotel and resort, following frontend web standards, accessibility guidelines, and clean code principles without relying on custom JavaScript frameworks.

---

## Website Overview

Hostello is a hospitality website designed to present accommodation options, hotel amenities, dining experiences, and booking availability. The website consists of 10 interconnected pages sharing a consistent layout, color palette, and typography:

- **Home (`index.html`)**: Hero carousel, booking search bar, room highlights, amenities overview, restaurant preview, guest reviews, and video showcase.
- **About Us (`pages/about_us.html`)**: Hotel background, key pillars, values, guest reviews, and FAQ accordion.
- **Room List (`pages/room_list.html`)**: Detailed accommodation catalog with pricing, amenities, and booking options.
- **Room Availability (`pages/room_availability.html`)**: Interactive calendar schedule and room status checker.
- **Amenities (`pages/amenities.html`)**: Grid of available services, wellness facilities, and leisure options.
- **Foods & Bars (`pages/foods.html`)**: Dining menu, restaurant showcase, and bar offerings.
- **Blog (`pages/blog.html`)**: Hospitality news, articles, travel guides, and sidebar categories.
- **Our Team (`pages/team.html`)**: Profiles of management and hospitality staff.
- **Reviews (`pages/comments.html`)**: Testimonial showcase and customer feedback.
- **Contact (`pages/contact.html`)**: Location details, inquiry form with labeled inputs, and customer support channels.

---

## Technologies Used

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<section>`, `<main>`, `<footer>`), single `<h1>` hierarchy per page, accessible form labels, and descriptive `alt` tags.
- **CSS3 & SCSS**: Modular architecture with partials, SCSS variables for typography and color schemes, custom mixins (`@mixin` and `@include`), and deep nesting.
- **Bootstrap 4**: Grid system (`container`, `container-fluid`, `row`, `col-*`), responsive breakpoints, cards, carousels, and utility classes, customized with dedicated styles.
- **Responsive Web Design**: Fluid layouts optimized across mobile (375px), tablet (768px), laptop (1024px), and desktop (1440px) with zero horizontal overflow.
- **Git & GitHub**: Version control tracking incremental milestones and project deployment.
